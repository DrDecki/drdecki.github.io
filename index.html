Quake II on the PS Vita with the Vulkan renderer from vkQuake2. The Vita has no Vulkan driver, so it runs on VkVita, which translates the Vulkan calls and shaders to the Vita's own graphics API.

What works

  • The whole single player campaign
  • The Reckoning, Ground Zero, Zaero and Capture the Flag
  • Deathmatch over Wi-Fi against other Vitas or PCs
  • Sound effects and the ogg soundtrack
  • 4x MSAA and 60 FPS almost everywhere

Installation

You need a Vita with HENkaku or Enso, VitaShell and your own copy of Quake II (Steam, GOG or CD, version 3.20).

  1. Install vkquake2.vpk with VitaShell.
  2. Create the folder ux0:data/vkquake2/baseq2.
  3. Copy pak0.pak, pak1.pak, pak2.pak and the players folder from your Quake II baseq2 folder into it.
  4. For music, copy track02.ogg to track21.ogg from the GOG or Steam release into baseq2/music.
  5. Start the game.

The mission packs go next to baseq2 into xatrix, rogue, zaero and ctf. Pick them under Game, change game.

A port of SuperTux 0.7.0, the jump'n'run with Tux. Run and jump through multiple worlds, stomp on enemies, grab power-ups and find secrets on the way.

Installation

  1. Download supertux2.vpk and supertux2.zip.
  2. Install supertux2.vpk with VitaShell.
  3. Extract supertux2.zip to ux0:/data/, so you end up with ux0:/data/supertux2/data.zip. Don't extract data.zip itself.
  4. Start the game from the LiveArea.

Saves and settings go to ux0:/data/supertux2/user. The game uses your Vita's system language, you can pick another one in the options.

All credit for the game goes to the SuperTux team. Build instructions are in the README on GitHub.

Installation

You need a PS Vita or PS TV with HENkaku or Enso and VitaShell.

  1. Install alephone.vpk with VitaShell.
  2. Download the games you want from the Aleph One scenarios page. All three Marathon games are free.
  3. Unzip them and copy every game into its own folder inside ux0:data/AlephOne/.
  4. Copy the contents of AlephOne.zip into ux0:data/.
  5. Start Aleph One from the LiveArea and choose a game.

It should look like this in the end:

ux0:data/AlephOne/Lua/
ux0:data/AlephOne/Plugins/
ux0:data/AlephOne/Marathon/
ux0:data/AlephOne/Marathon 2/
ux0:data/AlephOne/Marathon Infinity/

Each game folder has to contain the game files like Map, Shapes and Sounds directly. Fan scenarios get their own folder next to the others.

Cheats

Press Triangle in game, type a command and confirm with Enter. A few of them:

nrg()Recharge shields
otwo()Refill oxygen
kyt()Toggle invincibility
ammo()+10 ammo for all weapons
yourmom()Save the game anywhere

The full cheat list is in the README on GitHub.
